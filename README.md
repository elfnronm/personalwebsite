# Elif Önem — portfolio

Personal portfolio for frontend development and interface design work. Built with React and CSS, and deployed at [elfnronm.github.io/personalwebsite](https://elfnronm.github.io/personalwebsite/).

## Local development

```sh
npm ci
npm start
```

## Checks

```sh
npm run build
```

The GitHub Pages base path comes from `homepage` in `package.json`. Project images live in `public/assets`.
